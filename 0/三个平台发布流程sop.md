# 论文网课 · 三平台发布流程 SOP

> 适用：每一期网课视频在 B站 / 抖音 / 小红书 三平台的发布流程
> 原则：一次录母带 → 切三个版本 → 错峰发布 → 重心不平均
> 核心认知：**B站养人设、抖音拉流量、小红书做转化**——三者是漏斗的不同层，不是替代关系

---

## 一、三平台定位（先想清楚每个平台的角色）

| 平台 | 角色定位 | 投入级别 | 核心价值 |
|---|---|---|---|
| **B站** | 主阵地 | 重点投入 | 中长视频留存好、收藏率高、学生搜索命中、建立"专业UP主"人设 |
| **抖音** | 流量放大器 | 轻量投入 | 流量最大、起号最快，但完播难、转化浅 |
| **小红书** | 转化金矿 | 中量投入 | 搜索+收藏属性强，学生爱搜"论文选题/查重"，付费转化意愿最高 |

> 一句话：B站让你"被信任"，抖音让你"被看见"，小红书让你"被付费"。

---

## 二、三平台内容规格对照

每期录一条 B站完整版（母带），再切成抖音短版、小红书中版。

| 维度 | B站 | 抖音 | 小红书 |
|---|---|---|---|
| **时长** | 完整版 18–22 分钟 | 1–3 分钟精华 | 3–8 分钟（重实用） |
| **画面尺寸** | 16:9 横版 | 9:16 竖版 | 3:4 竖版 |
| **封面** | 横版，可用PPT加工页 | 竖版，大字+强对比 | 竖版，干货笔记风 |
| **标题字数上限** | 80 字符 | 30 字符 | 20 字符 |
| **标题策略** | 痛点+干货提示+必看标签 | 纯情绪钩子（短促好奇） | 痛点+必看，符号提信息密度 |
| **简介逻辑** | 完整干货目录（给确定感） | 3案例列表化，前3秒抓人 | 痛点→结论→清单，重收藏 |
| **开头** | 可铺垫 | 必须3秒入痛点，砍寒暄 | 直接抛问题 |
| **转化引导** | 评论/私信交流 | 评论区互动 | "收藏+滴滴我"双引导 |
| **合规要求** | 均不提"代写/代笔"，只留"交流/辅导"口子 | 同左 | 同左 |

## 三、封面制作规范

> 封面任务：3秒让人点开，不是展示内容。PPT页直接当竖屏封面=文字糊掉，必失败。

### 1. 优先从 PPT 选一页做内容基础
- 选有**数字钩子**或**强对比**的页（如柱图、误区vs正解）
- 第01期参考：P05"纠错成本柱图（1→3→8→18）"——数字是最强点击诱因

### 2. 三平台封面做法
| 平台 | 做法 |
|---|---|
| B站 | 可用PPT加工页：导出后字号调大、留白增大；或用豆包生成横版版 |
| 抖音 | 豆包生成竖版：大字主标 + 简化视觉 + 强对比 |
| 小红书 | 豆包生成竖版：标题 + "可收藏感"标签（如"动笔前必看"） |

### 3. 封面要素清单
- 大字主标（占画面1/3，醒目）
- 副标数字钩子（如"成本翻18倍"）
- 视觉：简化柱图/箭头（借PPT图意，放大简化）
- 配色：与PPT一致（象牙白/藏青低饱和），保持IP视觉统一
- 不出现人物（知识类视频，避免分散专业感）

### 4. 豆包生成提示词模板（直接复制修改）
```
生成一张[16:9横版/9:16竖版/3:4竖版]视频封面，学术低饱和风格，
象牙白背景配藏青色文字。主标题"[XXXX]"用超大加粗宋体居中，
副标题"[XXXX]"用较小字号放下方。画面[右侧/下方]放一个[简化柱状图/箭头]，
藏青色，[最后一个柱子/箭头尖]用赭红色突出。
整体干净、专业、有视觉冲击，适合知识类视频。不出现人物。
```

## 四、发布时间与顺序（错峰，别卡同一秒）

| 平台 | 发布时间 | 原因 |
|---|---|---|
| **B站** | 当晚 18:00–21:00 | 学生晚自习/宿舍刷B站高峰 |
| **抖音** | 当晚 20:00–22:00 | 抖音晚高峰，流量最大 |
| **小红书** | 次日上午 11:00–13:00 或晚 19:00–21:00 | 小红书午休/晚间浏览高峰 |

### 推荐发布顺序
1. **Day1 晚**：先发 B站完整版（主阵地，先把作品立住）
2. **Day1 晚**：同晚稍晚发抖音短版（拉一波流量）
3. **Day2**：发小红书中版（吃转化）

> 错峰好处：避免同时盯三平台评论回复（一个人忙不过来），且每平台都能在各自流量高峰吃推荐。

## 五、单期发布执行清单（照着走）

### A. 制作阶段
- [ ] 录制B站完整版（母带，PPT+口播直接出）
- [ ] 从母带剪抖音短版（1–3分钟，只留钩子+1干货点+引导，多花20–30分钟）
- [ ] 从母带剪小红书中版（3–8分钟，重实用）
- [ ] 用模板生成三平台标题+简介
- [ ] 制作三平台封面（B站横/P抖音竖/P小红书竖）

### B. 发布阶段
- [ ] Day1 18:00–21:00 发B站（完整版 + 横封面 + 长简介）
- [ ] Day1 20:00–22:00 发抖音（短版 + 竖封面 + 短简介）
- [ ] Day2 11:00–13:00 或 19:00–21:00 发小红书（中版 + 竖封面 + 清单简介）

### C. 发布后维护
- [ ] 发布后2小时内回复首批评论（各平台算法对早期互动敏感）
- [ ] 置顶一条引导评论（如"你卡在论文哪一步？评论区聊聊"）
- [ ] 记录三平台数据（播放/完播/点赞/收藏/私信数）→ 见第六节

## 六、精力分配（避免一个人累死）

一个人做三平台，最怕平均用力。按角色分配：

- **录制**：一次录完整版（母带）→ 工作量1
- **剪辑**：B站版基本不用剪；抖音/小红书版从母带抽精华重剪 → 工作量+0.5
- **运营重心**：
  - 前期重点 = **B站（人设）+ 小红书（转化）**
  - 抖音 = "顺手分发"（剪个短版丢上去，不重点维护）

> 一条母带切三版：工作量没翻三倍，触达翻三倍。

## 八、合规红线（必须遵守）

1. **公开内容（标题/简介/视频内）绝不出现"代写/代笔/包过"** —— 三平台对学术不端服务敏感，易封号
2. 公开只挂"辅导/指导/交流"，代写业务在私信用"范文/定制"承接
3. 私聊转化走"三句话"结构：共情 → 给方案+委婉词 → 给安心（原创/保密/分期）
4. 所有沟通保留记录，明示"风险由委托方知悉"
5. **网课账号是长期资产**（100期体系），别为短期代写订单让账号踩雷
